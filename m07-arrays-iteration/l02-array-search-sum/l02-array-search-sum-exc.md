# Lab 7.2 – Übung: Werte suchen, zählen, aufsummieren

**Dauer:** ca. 25 Minuten (kurze Übung, projektunabhängig)

## Szenario

Du berechnest Kennzahlen (Summe, Durchschnitt, Minimum, Maximum) über ein
festes Array.

## Baseline

Neue Klasse `ArrayStatistics` (kein Bezug zu einer Checkpoint-Datei nötig).

## Voraussetzungen

- Lab 7.1 abgeschlossen

## Aufgaben

1. Erstelle eine Klasse `ArrayStatistics` mit `main`-Methode.
2. Deklariere `int[] values = {42, 17, 73, 50, 8};`.
3. Berechne Summe und Durchschnitt aller Werte in einer Schleife.
4. Berechne in derselben oder einer weiteren Schleife Minimum und Maximum.
5. Gib alle vier Kennzahlen aus.
6. **Zusatz:** ergänze eine Zählung, wie viele Werte über dem Durchschnitt liegen.

## Checkpoint

Deine Ausgabe zeigt Summe 190, Durchschnitt 38.0, Minimum 8, Maximum 73.

## Fertig, wenn

- alle vier Kennzahlen korrekt berechnet werden,
- der Durchschnitt als Kommazahl (nicht ganzzahlig gerundet) ausgegeben wird,
- die Zusatzaufgabe 2 liefert (42 und 73 liegen über 38.0).

## Referenz

Kein Bezug zu `output/project/`; diese Übung ist eigenständig.
