# Übungen: Konstruktoren und Konsolen-I/O (Platzhalter)

**Status: Platzhalter.** Aufgabenformulierung nur anhand der IHV-Titel
(`3302_IHV (3).pdf` Kap. 5.1.2, 5.2.2, 5.3.2, 5.4.2); die offiziellen
Aufgabentexte stehen erst mit `3302_K05.pdf` zur Verfügung.

## 5.1.2 - import und static import (obligatorisch)

Ersetzen Sie einen vollqualifizierten Typnamen durch eine `import`-Anweisung;
probieren Sie zusätzlich einen `static import` für eine häufig genutzte
statische Methode.

## 5.2.2 - Objekt per Konstruktor mit Parametern erstellen (optional)

Instanziieren Sie eine Klasse mit einem parametrisierten Konstruktor statt
mit dem Standardkonstruktor.

## 5.3.2 - Methoden aufrufen und Referenzen übergeben (optional)

Initialisieren Sie ein Objekt mit einem anderen Objekt als Konstruktorargument
(Kompositionsbeispiel) und rufen Sie darauf Methoden auf.

## 5.4.2 - ArithmeticTrainer 0.0.1 (obligatorisch)

Lesen Sie eine Konsoleneingabe ein (z. B. über `BufferedReader`), wandeln Sie
sie in `int` um, und verwenden Sie den Wert als `userSolution` im bisherigen
`ArithmeticTrainer`-Code.
