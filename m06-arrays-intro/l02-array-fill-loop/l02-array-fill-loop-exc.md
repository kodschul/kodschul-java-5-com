# Lab 6.2 – Übung: Array in einer Schleife befüllen

**Dauer:** ca. 20 Minuten (kurze Übung, projektunabhängig)

## Szenario

Du befüllst und liest ein Array vollständig über Schleifen statt über
einzelne Zuweisungen.

## Baseline

Neue Klasse `ArrayFillLoop` (kein Bezug zu einer Checkpoint-Datei nötig).

## Voraussetzungen

- Lab 6.1 abgeschlossen

## Aufgaben

1. Erstelle eine Klasse `ArrayFillLoop` mit `main`-Methode.
2. Deklariere `int[] squares = new int[10];`.
3. Befülle das Array in einer Schleife mit den Quadratzahlen 1² bis 10².
4. Gib alle Werte in einer zweiten Schleife aus.
5. **Zusatz:** berechne in einer dritten Schleife die Summe aller Werte im Array.

## Checkpoint

Das Array enthält die Werte 1, 4, 9, ..., 100 in dieser Reihenfolge.

## Fertig, wenn

- die Befüllung ausschließlich über eine Schleife erfolgt (keine
  Einzelzuweisungen),
- die Ausgabe alle 10 Werte in der richtigen Reihenfolge zeigt,
- die Summe (385) korrekt berechnet wird.

## Referenz

Kein Bezug zu `output/project/`; diese Übung ist eigenständig.
