## 1.7.2 - Nützliche Tastaturkürzel Ihrer IDE (obligatorisch)

Erkunden Sie in Ihrer IDE:

1. Eclipse: `syso` + `[Strg]+[Leerzeichen]` -> erweitert zu
   `System.out.println()`. Probieren Sie auch `syserr` und vergleichen Sie
   die Javadoc mit der von `System.out.println()`.
2. Eclipse: innerhalb einer Klasse, außerhalb einer Methode,
   `[Strg]+[Leerzeichen]` -> `main` wählen, um die Hauptmethode generieren zu
   lassen.
3. IntelliJ: `sout` bzw. `serr` + `[Strg]+[Leerzeichen]`.

## 1.8.2 - Methoden aus der JRE System Library aufrufen (obligatorisch)

1. Neue Klasse `OutputMoreReturnValues_solution` mit `main` im Projekt/Modul
   `x01_Output_vs_ReturnValue`.
2. Rufen Sie drei weitere Methoden der Klasse `Math` auf und geben Sie deren
   Rückgabewert aus (die meisten brauchen Argumente).
3. Rufen Sie `System.currentTimeMillis()` auf, geben Sie den Rückgabewert
   aus, und lesen Sie die Javadoc: Wofür steht dieser Wert?
