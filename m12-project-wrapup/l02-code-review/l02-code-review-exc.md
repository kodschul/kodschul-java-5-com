# Lab 12.2 – Übung: Code-Review und letzte Verbesserungen

**Dauer:** ca. 25 Minuten (kurze Übung, aufbauend auf Lab 12.1)

## Szenario

Du prüfst deinen `GuessingGameApp`-Code aus Lab 12.1 anhand einer
Checkliste und verbesserst mindestens eine gefundene Schwachstelle.

## Baseline

Weiterentwicklung von `GuessingGameApp` aus Lab 12.1.

## Voraussetzungen

- Lab 12.1 abgeschlossen

## Aufgaben

1. Gehe die Checkliste durch: Fehlerbehandlung, Kapselung, Namensgebung, doppelter Code, Sonderwerte.
2. Notiere mindestens zwei Beobachtungen (positiv oder verbesserungswürdig) zu deinem eigenen Code.
3. Setze mindestens eine konkrete Verbesserung um (z. B. `.trim()`/`.equalsIgnoreCase(...)` bei einer Ja/Nein-Abfrage, oder eine klarere Methodenbenennung).
4. Teste danach erneut, dass dein Programm weiterhin korrekt funktioniert.

## Checkpoint

Mindestens eine konkrete, im Review gefundene Verbesserung wurde
tatsächlich im Code umgesetzt und getestet.

## Fertig, wenn

- die Checkliste vollständig durchgegangen wurde,
- mindestens eine Verbesserung nachweisbar im Code steckt,
- das Programm nach der Änderung weiterhin fehlerfrei läuft.

## Referenz

Kein separater Checkpoint für dieses Lab; die Verbesserungen fließen in
`output/project/checkpoints/checkpoint-m12-final/GuessingGameApp.java` ein.
