# Was ist Java, und woher kommt es?

Einstiegs-Storytelling für Tag 1, vor Kap. 1 (Einführung). Kein IHV-Stoff,
sondern Kontext, warum die Sprache überhaupt so aussieht, wie sie aussieht.

## Was ist Java?

- Eine Programmiersprache **und** eine Plattform: Java-Quellcode wird zu
  Bytecode kompiliert, der auf der Java Virtual Machine (JVM) läuft - nicht
  direkt auf einem Prozessor.
- Genau dieses Prinzip ("einmal kompilieren, überall laufen lassen") ist der
  Grund, warum wir in diesem Kurs zwischen Java-Compiler und JVM unterscheiden
  (siehe Kap. 1.5).

## Die Geschichte in Kürze

- **1991:** Ein kleines Team um James Gosling startet bei Sun Microsystems das
  "Green Project" - Ziel war zunächst Software für Unterhaltungselektronik
  (Set-Top-Boxen), nicht das heutige Internet.
- Die Sprache hieß zuerst **"Oak"** (nach einem Baum vor Goslings Büro) und
  wurde wegen Markenrechtsproblemen in **"Java"** umbenannt.
- **1996:** Java 1.0 erscheint offiziell, mit dem bis heute gültigen
  Versprechen "Write Once, Run Anywhere".
- **2006:** Sun stellt den Großteil von Java als Open Source (OpenJDK) zur
  Verfügung.
- **2010:** Oracle übernimmt Sun Microsystems und damit die Verantwortung für
  Java.
- **Seit 2017/2018:** fester 6-Monats-Rhythmus für neue Versionen, mit
  regelmäßigen Long-Term-Support-Versionen (siehe `java-versionen.md`).

Die Pointe für den Kurs: Java ist "nur" eine über 30 Jahre gewachsene, sehr
konservativ weiterentwickelte Sprache - kein kurzlebiger Trend. Das erklärt
sowohl ihre riesige Verbreitung als auch, warum sie manchmal "altmodisch"
wirkt (bewusste Abwärtskompatibilität statt ständiger Neuerfindung).
