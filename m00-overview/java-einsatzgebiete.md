# Wo wird Java eingesetzt - und wer nutzt es?

## Wo wird Java heute konkret eingesetzt?

- **Unternehmens-Backends:** ein Großteil der Banking-, Versicherungs- und
  Handels-IT weltweit läuft auf Java, oft mit dem Spring-Framework.
- **Android:** über viele Jahre die Standardsprache für native Android-Apps;
  heute konkurriert Kotlin, aber die JVM-Basis und viele bestehende Codebasen
  bleiben Java.
- **Big-Data- und Server-Infrastruktur:** zentrale Werkzeuge des
  Big-Data-Ökosystems (z. B. Hadoop) sind in Java geschrieben.
- **Bekannte Endnutzer-Software:** z. B. Minecraft (Java Edition) ist ein
  bekanntes Beispiel für eine in Java geschriebene Consumer-Anwendung.

## Wo kann Java grundsätzlich eingesetzt werden?

- Serverseitige Web- und Microservice-Anwendungen.
- Desktop-Anwendungen (Schwerpunkt dieses Kurses, siehe Kap. 1.1).
- Eingebettete Systeme und Chipkarten (Java Card).
- Große verteilte Systeme, sobald man über die in Kap. 1.1 bewusst
  ausgeklammerten Themen (Multithreading, Mehrbenutzerfähigkeit,
  Transaktionsverarbeitung) hinausgeht.

## Wer nutzt Java?

- Große, traditionsreiche Organisationen mit langlebigen Systemen: Banken,
  Versicherungen, Behörden - Bereiche, in denen Stabilität und
  Abwärtskompatibilität wichtiger sind als das neueste Sprach-Feature.
- Große Technologiekonzerne für Backend- und Plattformdienste, oft neben
  anderen Sprachen (Polyglot-Architekturen), nicht als einzige Sprache.
- Millionen einzelne Entwickler:innen über Lernplattformen, Hochschulen und
  Zertifizierungen - Java ist eine der am häufigsten an Hochschulen gelehrten
  Einstiegssprachen in die objektorientierte Programmierung.
