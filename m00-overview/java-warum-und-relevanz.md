# Warum Java lernen, und wie relevant ist es heute?

## Warum Java (und nicht eine andere Sprache)?

- **Plattformunabhängigkeit:** derselbe Bytecode läuft auf jedem System mit
  passender JVM - Windows, Linux, macOS.
- **Strenge Typisierung:** viele Fehler fallen schon beim Kompilieren auf,
  nicht erst beim Ausführen - hilfreich gerade beim Erlernen von Grundkonzepten.
- **Große, stabile Standardbibliothek (JRE System Library):** vieles, was man
  in diesem Kurs braucht (`Random`, `ArrayList`, `String`, ...), ist bereits
  vorhanden und muss nicht selbst gebaut werden.
- **Abwärtskompatibilität als Prinzip:** Code von vor 20 Jahren läuft in der
  Regel noch - ein bewusster Kontrast zu Sprachen mit häufigen Breaking
  Changes.
- **Großer Arbeitsmarkt:** Java gehört seit Jahrzehnten durchgehend zu den am
  meisten nachgefragten Sprachen in Stellenanzeigen für
  Anwendungsentwicklung.

## Wie relevant ist Java heute noch?

- Java taucht regelmäßig unter den meistgenutzten Programmiersprachen in
  unabhängigen Rankings auf (z. B. TIOBE-Index, Stack-Overflow-Umfragen) -
  nicht mehr allein an der Spitze wie in den frühen 2000ern, aber weiterhin
  fest etabliert.
- Der Grund liegt weniger in neuen Projekten als im schieren Bestand: eine
  enorme Menge geschäftskritischer Software läuft seit Jahrzehnten auf Java
  und wird gewartet, erweitert, selten komplett ersetzt.
- Moderne Java-Versionen (siehe `java-versionen.md`) haben viele Kritikpunkte
  von früher entschärft (z. B. `var`, Records, Pattern Matching, kürzere
  Release-Zyklen) - Java heute ist nicht dasselbe wie Java aus den 2000ern,
  auch wenn der Kern (Kap. 1-21 dieses Kurses) stabil geblieben ist.
