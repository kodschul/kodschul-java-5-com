# Übungen: If-then-else-if vs. switch-case (Platzhalter)

**Status: Platzhalter.** Aufgabenformulierung nur anhand der IHV-Titel
(`3302_IHV (3).pdf` Kap. 6.2.2, 6.3.4); die offiziellen Aufgabentexte stehen
erst mit `3302_K06.pdf` zur Verfügung.

## 6.2.2 - ArithmeticTrainer 0.0.2 (obligatorisch)

Ersetzen Sie eine Kette unabhängiger `if`-Anweisungen im bisherigen
`ArithmeticTrainer`-Code durch eine korrekte `if-then-else-if`-Kette, sodass
nur genau ein Zweig ausgeführt wird.

## 6.3.4 - ArithmeticTrainer 0.0.3 (obligatorisch)

Ersetzen Sie die `if-then-else-if`-Kette durch eine `switch`-Anweisung über
den Operator (`+`, `-`, `*`, `/`); achten Sie auf korrekte `break`-Anweisungen
in jedem `case`.
