# Übungen: Objekte erstellen (Platzhalter)

**Status: Platzhalter.** Aufgabenformulierung nur anhand der IHV-Titel
(`3302_IHV (3).pdf` Kap. 4.3.1, 4.5.2); die offiziellen Aufgabentexte stehen
erst mit `3302_K04.pdf` zur Verfügung. Status laut SLF: beide obligatorisch
(Tag 1).

## 4.3.1 - Ein Objekt mit sichtbarer Repräsentation erstellen (obligatorisch)

Erzeugen Sie ein Objekt (z. B. `new Random()`), speichern Sie die Referenz in
einer Variablen, und geben Sie über eine Methode des Objekts einen Wert aus.

## 4.5.2 - Fortsetzung: Objekt mit sichtbarer Repräsentation (obligatorisch)

Erweitern Sie die vorige Lösung: rufen Sie eine weitere Methode auf dem
gleichen Objekt auf und übergeben Sie die Referenz an eine zweite Stelle im
Code.
